SOLELEDGER

Privacy notice

Updated October 30, 2026

SoleLedger is a local inventory and listing tool used by Regen Collections LLC. This notice describes the current tool and its connection to the owner’s eBay seller account.

eBay account information

With the seller’s authorization, Ledger uses the seller identifier, authorization tokens, business policies, dispatch ZIP code, and listing information to prepare and publish selected listings. API records can include listing IDs, fees, warnings and eBay-hosted photo links. Credentials are encrypted on the local computer using OS-backed protection; they are not stored in this hosted website.

Photos and listing information

Original inventory photos and local inventory stay on the owner’s computer. Preparing an eBay preview sends selected resized photos and listing details to eBay. Publishing sends the approved listing request. Optional item identification sends selected photo copies to Google Gemini and uses Google Search. Authorized cross-listing sends item details and photos to Vendoo and the selected marketplaces. Those services process information under their own policies.

Account-deletion notifications

This separate hosted service receives eBay account-deletion notices, which can contain eBay user identifiers. It encrypts each accepted delivery for the local Ledger installation before storing it in a protected queue. The private decryption key stays on the owner’s computer. Ledger verifies eBay’s signature before removing a matching account’s stored eBay API data, then acknowledges the delivery so its queued copy is deleted.

Storage and retention

Local records remain until removed through the app or its account-deletion process. Queued notices wait while the local server is offline, so the owner must run Ledger regularly for prompt processing. Original inventory, user-created exports, backups, and records held by other services require separate management. Removing a local connection does not end existing marketplace listings.

The receiver is hosted using Sites and Cloudflare infrastructure, which may process technical request information for service operation and security. The receiver’s application code does not log notification bodies, seller credentials or tokens, and it does not use the notices for advertising.

Control and contact

The seller can revoke SoleLedger’s access in eBay’s third-party application settings and remove the saved seller connection in Ledger. For questions about this tool or its stored information, contact regencollectionsllc@gmail.com.
